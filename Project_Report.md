# AI Startup Success Predictor using Machine Learning

## Objective
Predict startup success using machine learning.

## ML Lifecycle
Data preparation, preprocessing, feature engineering, model training, evaluation and deployment.

## Model
Random Forest Classifier with numerical standardization and categorical one-hot encoding.

## Evaluation
Test accuracy: 95.00%

## Deployment
The Streamlit app loads the model with a path relative to `app.py`, avoiding deployment-specific absolute paths.
